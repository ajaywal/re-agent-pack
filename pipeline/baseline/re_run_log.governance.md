# Re-Run Log

Use this file to record controlled reruns after reviewer feedback or new evidence.

| Date | Slice | Trigger for Re-Run | Inputs Changed | Files Updated | Requested By | Outcome Summary |
|---|---|---|---|---|---|---|

## When to add an entry
Add a row when:
- a rule is rejected
- reviewer comments require targeted re-analysis
- new evidence is introduced
- dependency interpretation changes
- service/API mapping is revised after review

## Rules
- rerun only the impacted slice if possible
- do not regenerate unrelated artifacts unnecessarily
- summarize what changed
