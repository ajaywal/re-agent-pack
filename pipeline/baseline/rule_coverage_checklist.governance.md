# Rule Coverage Checklist

Use this checklist before declaring the slice sufficiently reverse-engineered.
Counters show actual / estimated totals. Estimated totals are set by the project-scanner.
Each analysis agent updates the actual count as it completes its work.

## UI Coverage
- [ ] All visible screens in scope have been reviewed (0 / ~0 estimated)
- [ ] All material controls have field/control entries (0 / ~0 estimated)
- [ ] All important buttons/actions have been mapped (0 / ~0 estimated)
- [ ] Visible labels have been interpreted carefully

## Event Coverage
- [ ] All primary user flows have been traced (0 / ~0 estimated)

## Rule Coverage
- [ ] Validation rules extracted (0 / ~0 estimated)
- [ ] State/routing rules extracted (0 / ~0 estimated)
- [ ] Persistence/audit rules extracted (0 / ~0 estimated)
- [ ] Integration/gateway rules extracted (0 / ~0 estimated)

## Dependency Coverage
- [ ] All service layers traced (0 / ~0 estimated)
- [ ] All external integrations identified (0 / ~0 estimated)
- [ ] All candidate APIs estimated (0 / ~0 estimated)

## Coverage gap scan
- [ ] Coverage gap scan run (rule-extractor Step 3)
- [ ] All flagged functions reviewed and either have rule cards or are confirmed out of scope
