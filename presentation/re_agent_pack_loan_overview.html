These are Agents, not Skills

  • Each agent has a role, a persona, and multi-step reasoning
  • The analysis-planner decides what to run next based on coverage gaps
  • The grounding-reviewer judges rule grounding and stamps Review Priority
  • The publication-reviewer issues Go / No-go on the final 7 deliverables
  • Each step runs as a separate agent in VS Code Copilot — the human advances through steps using pipeline/GUIDE.md
  • State is shared via session_state.governance.md — agents read it first every time

Skills would be…

  • Reusable functions called by agents (e.g. "parse a C++ file")
  • Stateless utilities with no persona
  • No decision-making — just execution
  • Examples: "extract function signatures", "format a markdown table"
  • Future: we may extract reusable skills from these agents in Phase 1.5

Loan Search  ·  Input Validation
R-L-001 At least one search criterion required (loan number or borrower name) LoanRules.cpp::ValidateLoanForSearch COBOL: TKA900
TKA900 paragraph 2000-VALIDATE-INPUT returns STATUS-CODE '9001' on empty request, blocking an unrestricted LSS_LOAN_T scan. UI layer mirrors this check — dual-layer enforcement.
R-L-002 Loan number must be exactly 10 digits LoanRules.cpp::ValidateLoanForSearch Tandem: LSS_LOAN_T
LOAN_NUM CHAR(10) NOT NULL — a shorter value misses the SQL equality index; a longer value is rejected at TME serialisation before the fgatetcp send.
R-L-003 Loan number must contain digits only LoanRules.cpp::ValidateLoanForSearch Tandem: LSS_LOAN_T
LOAN_NUM is a zero-padded numeric identifier. The Tandem SQL index is built on the numeric character set — alpha characters indicate a data entry error and would bypass index lookup.
Loan Search  ·  Premium Rating
R-L-004 QUOTE_REQD='Y' on the cycle step triggers a RataBase premium quote before display LoanRules.cpp::RequiresQuote Tandem: LSS_CYCLE_STEP_T
QUOTE_REQD CHAR(1) DEFAULT 'N' in LSS_CYCLE_STEP_T. TKA900 joins this table on CLIENT_ID and returns the flag in the LOAN_SEARCH response payload.
R-L-005 Property state must be in the 23-state approved carrier list for RataBase rating LoanRules.cpp::EnforceCarrierCoverage RataBase Config
RataBase has no configured rates outside the approved state list. Loans in unapproved states require manual underwriting — this rule prevents a failed rating call and routes the operator correctly.
R-L-006 Kentucky requires an ISO advisory pre-call (AIP930) before RataBase rating RataBaseServiceAdapter.cpp::GetQuote Tandem: AIP930
Mnemonic KY_ISO_QUERY → AIP930 via TME. RataBase rejects KY submissions without an ISO context block (fire class, territory, construction type).
R-L-011 Property value must be greater than zero before a RataBase rating request is submitted RataBaseServiceAdapter.cpp::GetQuote Tandem: LSS_LOAN_T
PROPERTY_VALUE defaults to 0 in the schema. The rating adapter blocks zero or negative values before any quote request.
Loan Search  ·  EDI Notification
R-L-007 EDI_FLAG must be 'Y' on the loan record to generate a 14E notification LoanRules.cpp::EnforceEdiEligibility Tandem: LSS_LOAN_T
EDI_FLAG CHAR(1) DEFAULT 'N'. Clients not enrolled in EDI must not receive outbound 14E.
R-L-008 Instant Issue cycle type suppresses 14E EDI output LoanRules.cpp::EnforceEdiEligibility Tandem: LSS_CYCLE_STEP_T
CYCLE_TYPE = 'INSTANT_ISSUE' suppressed — would create a duplicate at the servicer's EDI processor.
R-L-009 Form ID must be registered in lender_target before writing a 14E record LoanRules.cpp::EnforceEdiEligibility lender_target table
An unrecognised form ID produces a 14E record the downstream EDI processor cannot route.
R-L-012 FCI_CODE prefix 'BK' uses Black Knight fixed-width 14E format; all others use SSP delimited EDINotificationWriter.cpp::Write14ERecord EDI: Format routing
Format selection determines which downstream servicer processor handles the outbound record.
R-L-013 A suppressed or failed 14E notification must not block the operator from viewing the selected loan result LoanSearchDlg.cpp::ProcessLoanResult State transition
Write14ERecord() returning FALSE does not interrupt the display flow.
R-L-014 Each 14E dispatch must generate at least one loan audit entry with full context LoanRules.cpp::BuildLoanAuditMessages Audit rule
Audit messages built before dispatch and included in the TME request payload sent to 14E_NOTIFY → TKA920.
Loan Search  ·  Integration Gateway
R-L-010 TME mnemonic must be registered in LSS001T before a message can be sent TMELibAdapter.cpp::SendMessage Tandem: LSS001T
MNEMONIC → PROGRAM_NM mapping loaded from LSS001T at startup. An unmapped mnemonic is a configuration error requiring a Tandem DBA fix.
